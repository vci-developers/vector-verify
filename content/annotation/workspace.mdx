# Annotation Workspace

The Annotation Workspace is where you label individual specimens within a task.
It is designed for focused, efficient annotation — you move through specimens
one at a time and submit labels as you go.

## Layout

The workspace is divided into three areas:

- **Task header** — shows the task name, how many specimens you have annotated,
  and how many remain
- **Specimen display** — the main area showing the specimen image and its
  metadata
- **Annotation controls** — the fields and buttons you use to label the specimen

## Labeling a specimen

For each specimen, assign values for the following fields:

| Field               | Options                                            |
| ------------------- | -------------------------------------------------- |
| **Genus**           | Select from available genera                       |
| **Species**         | Select from species within the chosen genus        |
| **Sex**             | Male / Female / Unknown                            |
| **Abdomen status**  | Unfed / Blood-fed / Gravid / Semi-gravid / Unknown |
| **Image artifacts** | Blurry, missing parts, incorrect capture, etc.     |

Once you have filled in the fields, click **Submit** to record your annotation
and move to the next specimen.

## Other actions

- **Skip** — move past a specimen without annotating it; it will remain in the
  task for later
- **Flag** — mark the specimen as problematic without submitting a full
  annotation
- **Mark as ambiguous** — record that the specimen cannot be confidently
  identified

## Navigation

Use the **Next** and **Previous** buttons to move between specimens. You can
also return to the [Task List](/docs/annotation/tasks) at any time — your
progress is saved automatically.

## Progress indicator

The header always shows your current position in the task (e.g. "42 of 100
annotated") so you can track how much work remains.
