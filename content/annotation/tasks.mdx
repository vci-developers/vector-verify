# Annotation Tasks

The Annotation Tasks page lists all available annotation tasks. This is your
starting point when you are ready to annotate.

## Reading the task list

Each task in the list shows:

- **Task name** — a short label describing the task's purpose
- **Description** — more detail about what the task is for
- **Progress** — how many specimens have been annotated out of the total (e.g.
  25 / 100)
- **Status** — whether the task is not started, in progress, or completed

Tasks are grouped by status so you can quickly find ones that need work.

## Filtering tasks

Use the filter controls to narrow the list by:

- **Status** — show only tasks in a specific state
- **Date created** — find recently created tasks

## Starting or resuming a task

Click any task to open it. If you have previously started the task, you will be
taken directly to the next unannotated specimen. If the task is new, you will
start from the first specimen.

## Task status reference

| Status          | Meaning                                           |
| --------------- | ------------------------------------------------- |
| **Not started** | No specimens in this task have been annotated yet |
| **In progress** | Some specimens annotated, more remaining          |
| **Completed**   | All specimens in the task have been annotated     |

Once you open a task, you move to the
[Annotation Workspace](/docs/annotation/workspace).
