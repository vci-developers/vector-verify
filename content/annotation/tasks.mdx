# Annotation Tasks

The Annotation Tasks page lists the annotation tasks assigned to you. This is
your starting point when you are ready to annotate.

## Reading the task list

Each task card shows:

- **Task name** -- a unique task label
- **Status** — Pending, In Progress, or Completed
- **Progress** — how many specimens have been annotated out of the total
- **Assigned date** — when the task was assigned to you

## Task status tabs

Tasks are grouped into tabs by status. Switch tabs to focus on the work you
need.

### Pending

Tasks that have been assigned but not started yet. When there are none, the tab
shows "No annotation tasks found".

![The Pending tasks tab](/docs/annotation/01-tasks-pending.png)

### In Progress

Tasks you have started but not yet finished. Each card shows a progress bar.

![The In Progress tasks tab](/docs/annotation/02-tasks-in-progress.png)

### Completed

Tasks where every specimen has been annotated.

![The Completed tasks tab](/docs/annotation/03-tasks-completed.png)

## Filtering tasks

Use **Filter by date when task was assigned** to narrow the list to tasks
assigned within a specific date range.

## Starting or resuming a task

Click any task to open it. If you have already started the task, you are taken
to the next unannotated specimen; otherwise you start from the first specimen.

Once you open a task, you move to the
[Annotation Workspace](/docs/annotation/workspace).
