# User Roles

VectorVerify uses role-based access control. Every user is assigned one of four
access levels by a program administrator. Your level determines which pages you
can visit and which actions you can perform.

## Access levels

### Level 0 — Site Viewer

Read-only access to a single sentinel site.

- View household surveillance records for your assigned site
- View mosquito specimen images
- View dashboard metrics for your site

Cannot modify data or submit annotations.

---

### Level 1 — Program Viewer

Read-only access across all sites in a program.

- View household surveillance records for all sites
- View specimen data and images across the program
- Access program-level dashboards and analytics

Cannot modify data or submit annotations.

---

### Level 2 — Site Editor

Read and write access to a single sentinel site.

- View and edit household survey submissions for your site
- Correct site-level surveillance records
- Manage data associated with your assigned site

Cannot perform specimen annotation.

---

### Level 3 — Program Editor and Annotator

Full read and write access across all sites, plus annotation privileges.

- View and modify surveillance data across all sites
- Perform expert annotation of mosquito specimens
- Review and correct machine learning classification outputs
- Participate in model evaluation workflows

Typically assigned to expert reviewers, program supervisors, and researchers.

---

## Checking your access level

Your access level is set by your program administrator. If you believe your
access level is incorrect or you need elevated access, contact your
administrator directly.
