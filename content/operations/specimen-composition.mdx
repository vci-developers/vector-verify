# Specimen Composition

The Specimen Composition tab breaks down the specimens collected across the
selected district and time frame by species, sex, and abdomen status.

![Specimen composition charts](/docs/operations/02-specimen-composition.png)

## What you'll see

The tab shows three sections — **Species**, **Sex**, and **Abdomen status**.
Each section includes:

- A **total specimen count** with a composition breakdown
- A **time series** of specimen counts over the selected period, so you can see
  how the composition changes from month to month

## Using the filters

The charts respond to the shared Operations filters. Select a district and time
frame to update the breakdowns.
