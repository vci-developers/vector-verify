# Operations

The Operations page provides a centralized view of surveillance program
activity. It is designed for program managers, district supervisors, and
researchers who need to monitor what is happening across all sentinel sites.

## Shared filters

All tabs in Operations share the same filters:

- **District** — narrow the view to a specific administrative district
- **Sentinel site** — optionally focus on a single site within the district
- **Time frame** — select a month, a custom date range, or a predefined period

Changing any filter updates all tabs simultaneously.

## Tabs

The Operations page is organized into tabs, each focused on a different aspect
of program monitoring:

| Tab                                                               | What it shows                                                                                  |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **[Sites Overview](/docs/operations/sites)**                      | Site-level activity — sessions, specimens, and submission status per site                      |
| **[Metrics Dashboard](/docs/operations/metrics)**                 | Charts and aggregates covering catch trends, species composition, and data quality             |
| **[Geographical Summary](/docs/operations/geographical-summary)** | A map showing mosquito activity by village, sized and colored by specimen and Anopheles counts |
| **[Model Accuracy](/docs/operations/model-accuracy)**             | ML model performance based on annotation data — confusion matrices and accuracy trends         |
| **[VHT Compliance](/docs/operations/vht-compliance)**             | Field team activity — sessions per collector, missed collection days, coverage metrics         |
