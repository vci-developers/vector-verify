# Sessions

The Sessions tab lists individual sessions across sites and collection cycles,
independent of the Sites List grouping. By default Sessions shows results across
all locations you have access to.

![The Sessions tab with a sortable table of sessions, a Reassign Cycle dropdown per row](/docs/review-sessions/sessions-table.png)

## The sessions table

Each row is one session, with columns for Collection Cycle, Session, Site,
Collection Date, Session Created, and State. Click a column header to sort by
that column; click again to reverse the sort order. Click a Session ID to open
that session's review detail page.

Use the search box to filter sessions by site or session identifiers.

## Reassigning a session to a different collection cycle

Each row has a **Reassign Cycle** dropdown showing the session's current
collection cycle. If a session was recorded under the wrong cycle, choose a
different one from this dropdown.

If neither the session's current site/cycle nor the destination site/cycle has
already been certified or submitted, the reassignment applies immediately.

If either one has already been certified or submitted, you're asked to confirm
first, since reassigning will reset that entire review unit back to Needs
Review:

![The reassignment confirmation dialog, shown when the review unit has already been certified or submitted](/docs/review-sessions/reassign-confirm-dialog.png)
