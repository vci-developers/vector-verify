# Surveillance Questions Review

This is the first validation step after selecting a site and month. You review
the surveillance form responses submitted across all sessions to check for
inconsistencies.

## What this page shows

The page displays a table with surveillance questions as rows and session
responses as columns. This layout lets you compare answers side-by-side across
every session submitted for the month.

For example:

| Question          | Session 1      | Session 2      | Session 3       |
| ----------------- | -------------- | -------------- | --------------- |
| Collection method | CDC light trap | CDC light trap | Pyrethrum spray |
| Indoor/outdoor    | Indoor         | Indoor         | Indoor          |

## Conflict detection

The platform automatically highlights:

- **Conflicting responses** — where different sessions give different answers to
  the same question
- **Missing responses** — questions with no answer recorded for a session
- **Incomplete entries** — sessions with partially filled forms

Highlighted cells indicate where you should focus your attention.

## Resolving conflicts

For each conflict you find, you can:

1. Review the individual session records to understand the discrepancy
2. Mark the correct response
3. Flag the session for follow-up if you need more information
4. Add a note explaining your decision

## Completing this step

Once you are satisfied that surveillance questions are consistent and any
conflicts are resolved, confirm the step to proceed to
[Specimen Review](/docs/review/specimen-review).
