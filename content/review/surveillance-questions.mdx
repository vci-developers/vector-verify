# Surveillance Questions Review

This is the first validation step after selecting a site and collection cycle.
You review the surveillance form responses submitted across all sessions to
check for inconsistencies.

![The surveillance questions review table, with conflicting rows flagged and one row's value being edited](/docs/review-detail/surveillance-edit-any-row.png)

## What this page shows

The table has one row per surveillance question and one column per session
submitted for the site and collection cycle, plus a **Value** column where you
record the reviewed answer.

If a site has more than one review unit (for example, more than one household or
structure surveyed), the table is split into sections — one for session-level
questions, and one per unit — so you can review each unit's questions
separately.

## Row highlighting

Rows are flagged when:

- **Conflicting** — sessions give different answers to the same question
- **Required and unanswered** — a required question has no recorded answer

Rows can also be **disabled** (shown as N/A) when a question doesn't apply given
another answer — for example, "Months Since IRS" is disabled if "Was IRS
Conducted" is "No".

## Editing a value

Any non-disabled row can be edited. Click the pencil icon next to a row to make
its value editable, and select or enter the value you want recorded. Editing a
non-conflicting row is optional; resolving every conflicting or
required-unanswered row is necessary before you can continue.

## Completing this step

Once every conflicting and required-unanswered row has a value selected, **Save
& Continue** becomes enabled, taking you to
[Specimen Review](/docs/review/specimen-review).
