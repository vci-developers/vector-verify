# November 3, 2026 - Metadata Review, Prediction Editing & Clearer Charts

Here is a summary of changes shipped in this release.

## Metadata review

Forms are easier to fill in, and older sessions display their original answers
properly.

- Added a calendar picker to date questions
- Answers from earlier form versions now appear as read-only rows instead of
  being lost
- Fixed required-question checks being applied to questions from older form
  versions
- Dropdowns now show a placeholder when a saved answer is not one of the current
  options
- Restored the missing "Other" field on dropdown questions

![The calendar picker on a date question in metadata review](/docs/release-notes/2026-11-03/metadata-date-picker.png)

## Image review

You can now correct a specimen's predictions from any thumbnail.

- Edit genus, species, sex, and abdomen status directly from the thumbnail strip
- Thumbnails are now numbered, and long strips no longer overflow the page

![Editing a specimen's predictions in image review](/docs/release-notes/2026-11-03/image-review-prediction-edit.png)

## Operations

Specimen composition charts now show totals and percentages.

- Added a composition donut chart next to the bar chart
- Hovering a chart now shows each group's count and share of the total
- Legend order now matches the bar chart

![The species composition donut chart with totals and percentages](/docs/release-notes/2026-11-03/operations-composition.png)

## Miscellaneous

Smaller fixes across the app.
